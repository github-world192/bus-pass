# stop_id_map_v3.json 資料結構說明

此檔案為台北公車站點資料庫 (v3)，採用 **座標池化 (Geo Pooling)** 架構以縮減檔案體積並保留精確座標。

## 根物件結構

| 鍵 (Key) | 類型 | 說明 |
| :--- | :--- | :--- |
| **`v`** | `Integer` | 資料庫版本號 (固定為 `3`)。 |
| **`g`** | `Array` | **座標池 (Geo Pool)**。儲存所有不重複的經緯度組合。 |
| **`s`** | `Object` | **站點資料 (Stops)**。以 `SID` 為鍵，查詢站點基本資訊與座標索引。 |
| **`n`** | `Object` | **站名索引 (Names)**。以 `站牌名稱` 為鍵，查詢對應的 SID 列表。 |

## 詳細格式定義

### 1. 座標池 (`g`)
一個二維陣列，儲存浮點數座標。陣列的 **索引值 (Index)** 即為該座標的 ID。
* **格式**: `[ [Lat, Lon], [Lat, Lon], ... ]`
* **範例**: `[ [25.041, 121.565], [25.033, 121.564] ]`

### 2. 站點資料 (`s`)
* **Key**: `SID` (路線站點唯一識別碼)
* **Value**: `[ Name, SLID, GeoIndex ]`
    * `Name` (String): 站牌顯示名稱。
    * `SLID` (String): 站位代碼 (Stop Location ID)。
    * `GeoIndex` (Integer): 指向 `g` 陣列的索引值。
        * `>= 0`: 代表座標位於 `g[GeoIndex]`。
        * `-1`: 代表該站點無座標資料。

### 3. 站名索引 (`n`)
* **Key**: 站牌名稱 (如 "臺北車站(忠孝)")
* **Value**: `[ SID, SID, ... ]` (包含該名稱的所有 SID 列表)
